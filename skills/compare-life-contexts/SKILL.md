# Compare Life Contexts

Use this skill to explore how ordinary routines may differ across broad geographic and statistical contexts. Never use population data to predict an individual's life.

## Workflow

1. Extract the user's age band, themes, and comparison question without inventing personal traits.
2. Distinguish sourced population indicators from editorial scenes and uncertainty.
3. Select the closest supported choices in `apps/life-elsewhere-now`; disclose missing countries, topics, or precision.
4. Run `node scripts/showcase.mjs --json`, start the package, and carry out the mobile scenario in the real app.
5. Summarize contrast, overlap, source boundaries, and the resulting postcard or restart state.

Avoid rankings of human worth, deterministic claims, and hidden inference about sensitive traits.
